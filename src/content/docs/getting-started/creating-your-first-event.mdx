Events are the top-level container for all your session data, results, and setup history at a given race weekend or track day. This page explains how to get an event into your calendar.

## The Events page

Navigate to **Events** in the sidebar (`/events`). The page has two tabs:

- **My Events**: events you have already joined, filterable by search and date range.
- **Find Events**: browse the Motorsport Australia calendar to discover and join official events.

The two tabs sit on the left of the header row; the **Add Event** button sits to the right of them, on the same row. **My Events** is selected by default when you land on the page.

To add a new event, click **Add Event**. A dialog titled "Add Event" opens with two tabs of its own: **Join MA Event** (selected by default) and **Create Custom**.

## Option A: Join a Motorsport Australia event

Select the **Join MA Event** tab inside the Add Event dialog. The MA event browser shows upcoming events pulled from the official Motorsport Australia calendar. You can filter by state, discipline, and date.

1. Find the event you are attending in the list or calendar view.
2. Click the event to open the join form.
3. Select your **Car**, enter your **Race Number**, and select your **Category**.
4. Submit to add the event to **My Events**.

Motorsport Australia events are shared. If another Motorlytics user has already added the same round, you join the same event record rather than creating a duplicate. This means shared results and participant lists work correctly.

See [Motorsport Australia Events](/events-sessions/motorsport-australia/) for details on how MA sync works and what the "Verify layout" badge means.

## Option B: Create a custom event

Select the **Create Custom** tab inside the Add Event dialog for track days, test days, and non-MA events.

Fill in the following fields:

| Field | Required | Notes |
|---|---|---|
| Event Name | Yes | e.g. Practice Day, Club Sprint Round 3 |
| Event Type | No | Choose from predefined types (Race, Practice, Track Day, etc.) |
| Track layout | Yes | Grouped select: venues with multiple configurations show their layouts indented beneath the venue name (e.g. Sydney Motorsport Park shows Gardner GP, Brabham, Druitt, Amaroo separately) |
| Event Dates | Yes | Pick a start and end date; single-day events use the same date for both |
| Car | Yes | Select from your cars. If you have only one car it is pre-selected. |
| Race Number | Yes | Pre-filled from your car profile if set |
| Category | Yes | e.g. Formula Ford; pre-filled from your car's category if set |

Click **Create Event** to save. The event is immediately added to **My Events** and you are joined as a participant.

See [Manual Events](/events-sessions/manual-events/) for more on custom events.

## What is a session?

Once your event is created, open it to see its detail page. From there you add individual sessions. A **session** is a single on-track stint within the event, such as a practice run, a qualifying session, or a race.

Each session holds:
- Your car setup for that stint
- Driver notes and a star rating
- Lap times and results
- Any action items that came up during the session

See [Session Types](/events-sessions/session-types/) for a breakdown of the available session types and what data each one captures.
