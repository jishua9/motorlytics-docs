Motorlytics is one plan at **$15/month AUD**, with a **14-day free trial** on sign-up. No charge on the day you sign up. Annual billing is also available. Every subscriber gets the full feature set described below.

## Everything included

| Feature | Included |
|---------|:--------:|
| **Cars** | Up to 3 |
| **Custom Metrics** | Up to 25 |
| **Custom Setup Templates** | Up to 5 |
| Data Logger Import (MoTeC, AiM) | Yes |
| Telemetry Storage and Analysis | Yes |
| Corner Analysis | Yes |
| Lap Delta Comparison | Yes |
| G-Force Diagram | Yes |
| Session Health (engine/sensor gauges) | Yes |
| Driver Input Traces | Yes |
| Cost Tracking | Yes |
| Prior Part KM on replacement | Yes |
| Setup Sheets | Yes |
| Race Results Import | Yes |
| Pit Wall | Yes |
| Events and Session Management | Yes |
| Motorsport Australia Calendar Sync | Yes |

## Coming soon: Team features

Team features (shared cars, shared custom metrics and templates, Owner/Admin/Member roles) are on the roadmap and are not yet available. When released, team features will not require a separate purchase. Keep an eye on the changelog for updates.
