A venue like Sydney Motorsport Park can be driven in multiple configurations — Gardner GP, Brabham, Druitt, Amaroo — and each one is a fundamentally different circuit with a different lap length. Motorlytics models this split explicitly so lap-time comparisons and personal bests are always apples-to-apples.

## Tracks and TrackLayouts

Every circuit in Motorlytics is represented by two separate records:

- **Track** — the physical venue. Holds the venue name, location, GPS coordinates for weather lookup, and timezone. Sydney Motorsport Park is one `Track` record regardless of how many configurations it has.
- **TrackLayout** — a specific configuration of that venue. Holds the layout name, lap length in kilometres, number of turns, direction (clockwise / counter-clockwise), and the start/finish GPS coordinates used for automatic lap detection. Each layout belongs to exactly one `Track`.

When you create an event you pick a `TrackLayout`, not just a venue. This means a race meeting run on the Gardner GP configuration is permanently linked to that layout, and sessions from a separate meeting on the Druitt layout are kept completely separate. Career best-lap records, corner analysis, and telemetry aggregations all key on layout ID — different configurations never compete with each other.

## The Layout Lifecycle

Layouts progress through three verification states:

```text
catalog-only  →  GPS-verified  →  admin-reviewed
```

| State | What it means |
|-------|---------------|
| **catalog-only** | The layout is in the seeded catalog with known dimensions but no GPS start/finish data yet. |
| **GPS-verified** | Start/finish GPS coordinates have been extracted automatically from the first MoTeC upload recorded on this layout. Lap detection is active. |
| **admin-reviewed** | An admin has confirmed the layout details (length, turns, direction, and start/finish) using the admin tracks console. |

When a Motorsport Australia event is auto-imported, it defaults to the venue's primary layout. A yellow **"Verify layout"** badge appears on the event until the event creator or an admin confirms the correct configuration. This prevents situations where an event is inadvertently attached to the wrong layout before the schedule is published.

## Closed Venues

Venues that are no longer operating (for example Wakefield Park, which closed in 2022) are marked `inactive`. They are hidden from active layout pickers and new event creation, but all historical sessions and results linked to those layouts are preserved in full.

## Hand-Curated Australian Catalog

Motorlytics ships with 18 Australian permanent circuits and approximately 30 raceable layouts seeded out of the box. Multi-configuration venues are modelled in full — Sydney Motorsport Park, The Bend, Calder Park, Winton, Queensland Raceway, and Morgan Park all have their individual configurations listed as separate layouts in the picker.
