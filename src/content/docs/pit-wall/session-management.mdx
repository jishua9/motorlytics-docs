The **Sessions** card on the Pit Wall Dashboard is your schedule board for the weekend. From here you can add new sessions, track their status in real time, and jump straight into a session's detail page.

## Adding a session

1. On the Pit Wall **Dashboard** tab, locate the **Sessions** card in the left column.
2. Click **Add Session** in the card header.
3. Fill in the **Add Session** dialog:

   | Field | Options |
   |-------|---------|
   | **Session Type** | Practice, Qualifying, Race, Warmup, Test |
   | **Setup Template** | Any template available to your account (optional) |
   | **Date** | A dropdown of dates within the event weekend |
   | **Start Time** | Time picker in the track's local timezone |
   | **Time-based / Lap-based** | Toggle: time-based sessions take a duration in minutes; lap-based sessions take a lap count |
   | **Duration (minutes)** or **Number of Laps** | Depends on the toggle above |

4. Click **Create Session**.

The new session appears immediately in the schedule, grouped under its session type.

## Session status indicators

Sessions are grouped by type in the order Practice → Qualifying → Race. Within each group they are sorted by session number. Each session row shows:

| Indicator | Meaning |
|-----------|---------|
| Green checkmark + green left border | **Completed**: session end time has passed |
| Arrow icon + highlighted border | **Next / In Progress**: this is the active or next upcoming session |
| Dimmed circle | **Upcoming**: not yet started |

The title bar countdown timer and the session status stay in sync automatically.

## Viewing lap stats

For completed sessions, the right side of each row shows:
- **Best lap** time
- **Delta to baseline** (best lap and average lap) relative to the Quick Stats baseline session

The baseline session is indicated with a "baseline" label. Sessions faster than the baseline show deltas in green; slower sessions show them in red.

## Navigating to a session

Click any session row to open its full detail page at `/events/[id]/sessions/[sessionId]`. From the session page, the **Back to Pit Wall** link returns you here.

## Action Items

Below the Sessions card, the **Action Items** card tracks tasks for the car during this event. Items have three priority levels:

| Priority | Colour |
|----------|--------|
| **Urgent** | Red |
| **Before Next Event** | Amber |
| **When Convenient** | Subdued |

Type a task description, select a priority, and press enter to add it. Completed items can be checked off to remove them from the list. Action items created on the Pit Wall are linked to the event so they stay visible in the car's maintenance history.
