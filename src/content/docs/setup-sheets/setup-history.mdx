The Setup History panel gives you instant access to setups you have used at the same track with the same car. It sits alongside the setup entry form in every session and helps you build on what worked before, or understand why a session was different.

## The History panel

Inside a session, the **Setup Sheet** tab is split into two panels:

- **Left (History)**: previous sessions at the same track layout with the same car, sorted by how closely the conditions match the current session (weather, temperature, track state).
- **Right (Entry form)**: the live setup sheet for the current session.

Collapse the history panel with the arrow icon on its left edge to give the entry form more space.

### What each history item shows

Each entry in the panel displays:

| Item | Details |
|------|---------|
| Session type and number | e.g., "Practice 1" |
| Event name and date | |
| Session rating | 1 to 5 stars if rated |
| Weather summary | Condition icon + temperature |
| Car feedback badges | Balance, stability, grip, braking, acceleration |

Entries at the top of the list that are a strong weather match are highlighted as **Top Match**.

### Previewing a previous setup

Click any history item to expand it. While it is expanded, orange indicator values appear next to each input in the entry form, showing what was recorded in that session. This lets you compare your current entries against a previous setup without leaving the form.

Click the item again to collapse it and hide the preview values.

### Copying a previous setup

1. Expand a history item by clicking it.
2. Click **Copy Setup**.
3. Motorlytics merges the copied values into the current form. Existing values are overwritten where the metrics overlap.
4. A "Setup copied" toast confirms the action. Auto-save triggers within a second.

You can undo accidental copies by clicking a different history item and copying that setup instead, or by manually correcting individual fields.

## Per-car template configurations

Beyond the session history, Motorlytics lets you save a customised version of a template specifically for one car. This is called a **Car Setup Configuration**.

A configuration stores any template-level customisations (default values, metric visibility) alongside the car, so the template behaves consistently every time that car is used, even if the template itself is updated later.

### Setting a default template for a car

1. Go to **Cars** and open the car.
2. Open the **Setup** tab.
3. In the **Templates** list, select the template you want as default.
4. Click **Set as default** on the template item.

Once set, that template loads automatically when you start a new session with the car. The template name appears in the session's **Setup Sheet** header.

### Changing the template for a session

If a session needs a different template to the car's default, navigate to the car's **Setup** tab, select the alternative template, and it will apply to sessions using that selection. You can switch back to the default at any time.

## Auto-save

The setup entry form auto-saves every time you pause typing for approximately 0.8 seconds. A status indicator in the top right of the form shows:

- **Saving...**: a save is in progress
- **Saved**: the last save was successful (clears after 2 seconds)
- **Unsaved changes**: changes exist but the debounce timer has not yet fired
- **Save failed**: a network or server error occurred; try again or refresh

There is no manual save button. If you navigate away with unsaved changes, wait for the "Saved" indicator before closing the tab.
