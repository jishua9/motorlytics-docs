Every session has a **Setup** tab where you record your car's configuration — ride heights, tyre pressures, damper settings, wing angles, and anything else defined in your setup template. Changes are auto-saved as you type.

## Opening the setup sheet

1. Navigate to **Events**, open the event, and click the session you want to set up.
2. The session detail page opens with the **Setup** tab active by default.
3. The setup sheet title shows the template name and car. If no template is assigned to this session, Motorlytics falls back to the car's default template.

## Assigning a template

The template shown is resolved in this order:

1. A template explicitly set on the session (editable via **Edit Session**).
2. The car's **Default Template** set in the car profile.
3. No template — the Setup tab will prompt you to assign one via your car's settings.

See [Setup Templates](/setup-sheets/templates/) to create or choose a template.

## Filling in setup values

1. The sheet is divided into **sections** (for example, *Suspension*, *Aero*, *Brakes*) as defined by the template.
2. Click any metric field and type the value. Metrics can be number fields, select dropdowns, or text fields depending on how they were defined.
3. For **corner-based metrics** (marked FL / FR / RL / RR), four separate inputs appear side-by-side — one per corner. Enter each independently.
4. Changes are saved automatically — a brief **Saving…** then **Saved** indicator appears in the header. You do not need to press a save button.

## Selecting a tyre set

The **Tyre Set** selector in the setup header lets you record which set of tyres you are running for this session.

1. Click the **Tyre Set** dropdown next to the template name.
2. Select the tyre set from your car's tyre inventory.
3. The selection is saved as part of the session's setup data.

## Using setup history

The collapsible left panel shows **Setup History** — previous sessions on the same car at the same track, ranked by how closely the weather conditions match today's.

1. Hover over a history item to preview those values overlaid on the current sheet (values change colour to indicate they differ from your current entry).
2. Click **Copy** on a history item to paste all its values into the current sheet. You can then adjust individual metrics as needed.
3. Click the **collapse** icon (panel arrow) to hide the history panel and give more space to the setup form.

## Session rating

The star rating at the top-right of the Setup tab lets you rate the session from 1 to 5 during or after the session. Click a star to save — this is independent of the post-session completion rating.
