Manual events let you add any track day, test day, or club event that does not appear in the Motorsport Australia calendar. When you create a manual event you are automatically joined as a participant.

## Creating a manual event

1. Navigate to **Events** in the sidebar.
2. Click the **Add Event** button in the top-right corner of the Events page. A dialog opens.
3. Fill in the **Event Name** (for example, *Club Sprint Round 3* or *Practice Day*).
4. Choose an **Event Type**:
   - *Race Meeting*: competitive race weekend.
   - *Test Day*: private testing session.
   - *Practice Day*: open practice.
   - *Track Day*: non-competitive track day.
   - *Shakedown*: short shakedown run after maintenance.
   - *Other*: anything else.
5. Select a **Track layout** using the grouped picker (see below).
6. Pick the **Event Dates** using the date-range picker. Click the start date, then the end date. For a single-day event, click the same date twice.
7. Select the **Car** you are entering.
8. Enter your **Race Number** (auto-filled from the car profile if one is saved).
9. Enter your **Category** (auto-filled from the car profile if one is saved).
10. Click **Create Event**. The event is created and added to your **My Events** tab.

## Using the Track Layout Picker

The track layout picker groups venues with multiple configurations under a single header, so you can always pick the exact layout being used.

- Venues with **one active layout** appear as a single item, for example *Phillip Island Grand Prix Circuit*.
- Venues with **multiple layouts** appear as a header with indented layouts below, for example *Sydney Motorsport Park* shows *Gardner GP*, *Brabham*, *Druitt*, and *Amaroo* as separate options.

Select the layout that matches the configuration for your event. Choosing the correct layout matters because lap times, telemetry, and corner analysis are keyed to the layout. Results from different configurations are never mixed together.

## Editing or deleting a manual event

Only the event creator can edit or delete a manual event, and deletion is blocked once any participant has joined.

- To edit, open the event detail page and use the **Edit** option in the event menu.
- To delete, use **Delete Event** in the same menu. You will see an error if other drivers have already joined.

Motorsport Australia events cannot be edited or deleted.
