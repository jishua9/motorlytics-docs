Corner analysis is included with your Motorlytics subscription. Corners must be defined for the track layout by an admin before the table populates.

The corner analysis table appears in two places:

- **Lap Delta tab**: scroll below the delta and speed charts to find the **Corner-by-Corner Analysis** section.
- **Track Map tab**: open the data panel and select the **Corners** tab.

## Reading the table

Each row is one corner. Columns are grouped by lap, with four sub-columns per lap:

| Sub-column | What it shows |
|------------|---------------|
| **Entry** | Average speed (km/h) across the first three GPS points in the corner zone |
| **Min** | Minimum speed (km/h) reached anywhere in the corner (the apex speed) |
| **Exit** | Average speed (km/h) across the last three GPS points in the corner zone |
| **Time** | Total time (seconds) spent inside the corner zone |

Corner names are shown with a direction label in parentheses: **LEFT**, **RIGHT**, or **CHICANE**.

### Reference lap comparison

When a reference lap is set, the **Time** column for every other lap gains a delta indicator:

- A **green downward arrow** and a time value (e.g. `0.043`) means this lap was faster through that corner than the reference.
- A **red upward arrow** means it was slower.

The legend below the table reads: **Faster than reference** (green) and **Slower than reference** (red). All speeds are in km/h.

## Selecting laps for comparison

In the **Lap Delta** tab, use the lap selector panel to set a **reference lap** and add **comparison laps**. The best lap defaults to the reference. In the Track Map data panel, laps are controlled by the floating lap selector on the map itself.

## No corners defined

If the table shows "No corners defined for this track", the track layout has not been set up with corner zones yet. This is an admin operation performed at `/tracks/[id]/corners/edit`. Contact your series administrator or team owner to request corners be defined.

If the table shows "Track information not available", the session's event is not linked to a track layout.

## How corner zones work

Corners are defined by an admin clicking entry and exit points on the GPS map for each turn. The system uses Haversine distance calculations to convert GPS coordinates into cumulative track distances (metres from start/finish). During analysis, each GPS trace point is matched to the nearest corner zone and the entry/apex/exit speeds are extracted from that slice of the trace.

Because corners belong to a specific **track layout**, analysis stays accurate when a venue runs different configurations (e.g. Sydney Motorsport Park Gardner GP vs Brabham). Corners from one layout never bleed into another.
